- 로컬 적용, 커밋, push, 운영 배포를 서로 다른 상태로 구분합니다.
- 운영 상태는 배포 성공과 운영 URL 확인이 끝난 뒤에만 갱신합니다.
- 앱 공개 여부는 `content/apps.ts`의 실제 공개 설정과 라우팅 동작을 기준으로 기록합니다.
- 코드나 정책의 과거 상태는 Git 이력으로 보존합니다.
